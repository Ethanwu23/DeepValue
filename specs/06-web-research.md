# DV-06 新闻与行业研究

状态：Accepted（随本 PR 合并到 dev 生效）；版本：1.0；日期：2026-10-25。
关联：[Issue #8](https://github.com/Ethanwu23/DeepValue/issues/8)。公共约束：[总规约](00-system-contract.md)。本文件定义目标行为，不宣称已实现。

## 1. 目标与范围

独立 collect_news/collect_industry 节点，共享抓取解析服务；公司事件、行业需求及有出处的竞争关系。

非目标：绕过付费墙、搜索摘要替代正文、仅凭关键词认定竞争对手。

## 2. 现状、复用与变更

现有实现（相对 backend/src/agent，前端及根目录文件除外）：value/evidence.py:ArticleParser、read_page、verify_page、collect_web；base_agent.py:WebSearchAgent。

复制现有抓取限制；修复全页面日期混入和 DNS 校验与连接分离问题，保留失败记录。

迁移必须先复制对应实现到目标模块再改写；新增能力没有既有实现时明确新增，不复制不相关代码。

## 3. 输入与输出

- 输入：news/industry ResearchTask、Context、CompanyProfile。
- 输出：CollectorResult，候选证据及逐条拒绝记录。
- 依赖：DV-05、DV-08、DV-15。
- 数据字段、状态、日期和预算使用总规约，不自定义同义字段或隐式空成功。

## 4. 行为规则

1. 复用已验证的 MCP JSON 加 count 协议；每任务最多一次逻辑搜索、5 个候选页面，页面并发最多 3；时间窗口默认截止日前 365 天。
2. 正文提取限定主体文章及相应 Article/NewsArticle JSON-LD；导航/推荐文章的日期不能用于正文。原始 HTML 与选定主文标识需保留。
3. 发布日期须有唯一可验证日期。带时区时间转纽约判断；仅日期使用 date 精度。缺失、冲突、无时区且无法确定来源时区则拒绝；已知修改时间超 cutoff 则拒绝。
4. 正文至少 200 字符，保存全文解析文本及哈希；模型用选定片段，总长受输入预算约束，不把截断后的片段标为全文。
5. news 必须能定位公司名称或已核验别名及事件段落；industry 必须定位机械行业主题或出处明确的竞争关系。无关来源拒绝，不用收录数证明相关性。
6. 竞争对手关系是带引用的候选观察，不自动形成同业估值组。转载聚为 source_group，不能算独立支持。
7. 仅 HTTP(S) 公网，逐跳校验最多 4 次跳转、单页 2 MB。连接必须使用已校验的公网解析结果或校验实际 peer IP，防止校验后重新 DNS 解析导致访问内网。拒绝凭据 URL、私网/回环和非常用端口。
8. 网页来源固定标记 live_page；即使日期通过，也不宣称拥有历史归档。失败产生拒绝/缺口，不从 snippet 生成通过证据。

## 5. 失败、预算与安全

使用总规约 ErrorInfo 和全局 BudgetLedger；外部请求仅经 DV-15，实际发出前预留预算。业务缺口与系统异常分开，不以默认值、空对象、备用模型或备用来源掩盖错误。取消和终态优先级由 DV-13 统一控制，纯计算能力也不得提交已取消运行的结果。

本能力的特殊失败行为已在上面的规则与下面的场景中规定；不可恢复的供应商协议错误进入缺口，内部不变量错误由运行时标记 failed。

## 6. 验收场景

| 编号 | 场景 | Given | When | Then |
|---|---|---|---|---|
| DV-06-AC-01 | 合法文章 | 主体文章日期在 cutoff 前且相关 | 采集 | 接受并记录时间依据、内容哈希和主题 |
| DV-06-AC-02 | 推荐日期 | 主文章日期与推荐文章不同 | 解析 | 只绑定主体元数据，无法确定主体则拒绝 |
| DV-06-AC-03 | 晚修改 | 发布在 cutoff 前但已知修改在后 | 核验 | 拒绝并说明修改时间 |
| DV-06-AC-04 | 搜索无正文 | 只有 snippet 或少于200字符 | 采集 | 不得作为正文证据 |
| DV-06-AC-05 | 跨类别同源 | 新闻和行业找到同一正文 | 登记 | 合并主题，独立来源数仍为1 |
| DV-06-AC-06 | 网络边界 | 重定向或 DNS 重绑定指向私网 | 请求 | 不向私网发送请求，记录 NETWORK_POLICY_REJECTED |
