# DV-03 财报与市场数据

状态：Proposed；版本：1.0；日期：2026-10-25。
关联：[Issue #5](https://github.com/Ethanwu23/DeepValue/issues/5)。公共约束：[总规约](00-system-contract.md)。本文件定义目标行为，不宣称已实现。

## 1. 目标与范围

本轮实现年度 10-K、10-K/A 识别，以及截止日前一年最多 3 份与结果/重大事件相关的 8-K 正文。

非目标：市场行情适配器、股价与安全边际属于目标架构后续增量，v1 明确 market_data=not_supported；不因未实现行情阻断 PE 情景，也不宣称该部分完成。

## 2. 现状、复用与变更

现有实现（相对 backend/src/agent，前端及根目录文件除外）：value/sec.py:sec_json、rows_from_columns、collect 选报部分。

复制现有选报逻辑后修正按行数提前停止、列长度静默截断；将 I/O 与选报纯函数拆开。

迁移必须先复制对应实现到目标模块再改写；新增能力没有既有实现时明确新增，不复制不相关代码。

## 3. 输入与输出

- 输入：CompanyProfile、截止日、years、采集任务。
- 输出：FilingSet、公告 EvidenceCandidate、结构化 ResearchGap。
- 依赖：DV-02、DV-05、DV-15。
- 数据字段、状态、日期和预算使用总规约，不自定义同义字段或隐式空成功。

## 4. 行为规则

1. 读取 recent 与相关历史索引；列长度不一致必须报协议错误，禁止 zip 静默截断。
2. 先按 filingDate <= as_of、reportDate <= as_of 筛选。按 reportDate 倒序取最近 years 个不同财年，原始 10-K 为对应期间最早披露的原始申报。
3. 历史索引分页不能只根据已有 10-K 数量停止；在预算内覆盖选择期间及其截至 cutoff 的修订索引范围。未完成覆盖则返回 AMENDMENT_COVERAGE_INCOMPLETE 并阻断财务门禁。
4. 相同 accession 重复目录去重；同一时期多个不一致原始申报保留冲突，不任意选择。
5. 存在截止日前同期间 10-K/A 时标记 AMENDMENT_REVIEW_REQUIRED；v1 不自动解释修订内容、不覆盖原值、不放行估值。
6. 公告沿用 SEC 官方目录与正文 URL，限定 8-K 的 Item 2.02/5.02/8.01，按披露日倒序选择至多 3 份。存档 URL 和附件定位保留；不将公告替代年度数据。
7. 保留原始 JSON/正文的内容哈希及本地 artifact_id，所有下载计预算。官方附件不可读时记录缺口，不改用转载冒充原文。

## 5. 失败、预算与安全

使用总规约 ErrorInfo 和全局 BudgetLedger；外部请求仅经 DV-15，实际发出前预留预算。业务缺口与系统异常分开，不以默认值、空对象、备用模型或备用来源掩盖错误。取消和终态优先级由 DV-13 统一控制，纯计算能力也不得提交已取消运行的结果。

本能力的特殊失败行为已在上面的规则与下面的场景中规定；不可恢复的供应商协议错误进入缺口，内部不变量错误由运行时标记 failed。

## 6. 验收场景

| 编号 | 场景 | Given | When | Then |
|---|---|---|---|---|
| DV-03-AC-01 | 未来申报 | 2024 财报在 cutoff 之后披露 | 选报 | 不能用该财报，即使 reportDate 在截止日前 |
| DV-03-AC-02 | 历史修订 | 已有足够 10-K 但修订在历史分片 | 读取目录 | 继续检查覆盖范围并识别修订 |
| DV-03-AC-03 | 重复年度 | 同年度目录记录重复 | 选择 3 财年 | 按 accession 去重后取得 3 个不同期间 |
| DV-03-AC-04 | 修订阻断 | 截止日前有同期间 10-K/A | 构造 FilingSet | 返回修订缺口，财务门禁不可通过 |
| DV-03-AC-05 | 索引异常 | 列长度不同或索引预算耗尽 | 选择财报 | 分别返回协议错误或覆盖缺口，禁止完整标记 |
| DV-03-AC-06 | 公告范围 | 找到 4 份符合 Item 的 8-K | 采集 | 仅取最近 3 份，保留披露日、Item 与正文来源 |
