# DV-15 外部接入与运行配置

状态：Proposed；版本：1.0；日期：2026-10-25。
关联：[Issue #17](https://github.com/Ethanwu23/DeepValue/issues/17)。公共约束：[总规约](00-system-contract.md)。本文件定义目标行为，不宣称已实现。

## 1. 目标与范围

现有模型/MCP 协议复用，新增 FRED 接入；统一配置、超时、取消与日志。

非目标：静默备用模型、备用数据源、旧协议兼容、多层无限重试。

## 2. 现状、复用与变更

现有实现（相对 backend/src/agent，前端及根目录文件除外）：base_agent.py、llm/llm.py、configuration.py、app.py、logger.py；run*.sh。

先复制现有协议解析；删除 MCPAgent 返回 None、模型默认列表、广泛异常重试等兜底。避免重写已验证的供应商格式。

迁移必须先复制对应实现到目标模块再改写；新增能力没有既有实现时明确新增，不复制不相关代码。

## 3. 输入与输出

- 输入：显式环境配置、版本化服务契约、预算与取消信号。
- 输出：通过校验的 ConfigSnapshot、标准适配器结果、脱敏诊断。
- 依赖：总规约。
- 数据字段、状态、日期和预算使用总规约，不自定义同义字段或隐式空成功。

## 4. 行为规则

1. 启动前验证 APP_TOKEN、LLM_BASE_URL、MCP_APP_ID、AVAILABLE_MODELS、SEC_USER_AGENT、FRED_API_KEY；错误时明确失败，不生成默认模型列表。模块导入可独立于启动校验，CI 图装配不需生产凭据。
2. SEC_USER_AGENT 为应用及真实联系信息，从本地 env 读取，不能写入公开配置快照或日志。FRED key 只用于请求，不保存带密钥 query URL。
3. 保留搜索 MCP 对象+数量的完整协议验证；count 不匹配、工具错误、字段错误均为不可重试协议失败。
4. HTTP/搜索调用每个逻辑请求最多 2 次尝试；只对连接超时、429、502/503/504 重试，最多等待5秒，超预算即停止。4xx、解析失败不重试。禁用底层 SDK 隐含重试，避免叠乘。
5. 模型网络失败沿用有限重试；结构不合法不再重复整个模型调用，返回 MODEL_OUTPUT_INVALID。每次请求传递剩余截止时间。
6. 默认 HTTP40秒、网页12秒、模型60秒上限；全局截止时间优先；SEC 请求间隔不少于0.3秒，单进程协调；搜索 QPS 显式配置，值须为正。
7. 保持本地127.0.0.1服务和现有 npm/venv 启动方式；启动检测端口，退出只终止自己创建的子进程。
8. 日志仅记录 ID、状态、耗时、字节数与脱敏错误；关闭现有整段 HTTP body 日志。配置快照保存非敏感字段及版本 hash，不保存密钥 hash。
9. 凭据不进 git、导出、Issue、CI；CI 使用固定样本与替身，不向真实服务发付费请求。真实接入验收单独执行并记录脱敏证据。

## 5. 失败、预算与安全

使用总规约 ErrorInfo 和全局 BudgetLedger；外部请求仅经 DV-15，实际发出前预留预算。业务缺口与系统异常分开，不以默认值、空对象、备用模型或备用来源掩盖错误。取消和终态优先级由 DV-13 统一控制，纯计算能力也不得提交已取消运行的结果。

本能力的特殊失败行为已在上面的规则与下面的场景中规定；不可恢复的供应商协议错误进入缺口，内部不变量错误由运行时标记 failed。

## 6. 验收场景

| 编号 | 场景 | Given | When | Then |
|---|---|---|---|---|
| DV-15-AC-01 | 缺配置 | AVAILABLE_MODELS 无效或 FRED_API_KEY 缺失 | 启动服务 | 报具体配置项，不能使用默认模型或静默跳过宏观 |
| DV-15-AC-02 | 导入隔离 | CI 无生产密钥 | 加载静态图定义 | 不调用外部服务；启动校验可单独测 |
| DV-15-AC-03 | 协议破坏 | MCP 数量错误或 pages 字段非法 | 解析 | SOURCE_SCHEMA_ERROR，不重试 |
| DV-15-AC-04 | 网络重试 | 第一次429、第二次成功 | 执行 | 恰好两次计账，等待与预算受限 |
| DV-15-AC-05 | 结构失败 | 模型返回非法 JSON | 解析 | 一次结构失败，无无限重新生成 |
| DV-15-AC-06 | 日志脱敏 | 请求含 token、FRED query key、用户私有内容 | 记录日志 | 仅记录允许字段，错误不泄露响应原文 |
| DV-15-AC-07 | 生命周期 | 其他进程占端口或停止本应用 | 启停 | 拒绝冲突启动，不杀其他进程 |

- 当前阶段仅定义场景，不创建测试脚本。目标路径为计划，须与迁移矩阵一起随实现更新。
