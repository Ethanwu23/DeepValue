# DV-01 研究范围

状态：Accepted（随本 PR 合并到 dev 生效）；版本：1.0；日期：2026-10-25。
关联：[Issue #3](https://github.com/Ethanwu23/DeepValue/issues/3)。公共约束：[总规约](00-system-contract.md)。本文件定义目标行为，不宣称已实现。

## 1. 目标与范围

单公司、美国机械制造业 SIC 3500–3599；固定截止日及 PE 假设。

非目标：多公司筛选、自动扩大行业、自动替换标的或模型。

## 2. 现状、复用与变更

现有实现（相对 backend/src/agent，前端及根目录文件除外）：value/models.py:ResearchRequest；value/workflow.py:define_scope。

保留范围和排序校验；统一时区、严格整数与小数语义，移除松散 dict 在模块之间传播。

迁移必须先复制对应实现到目标模块再改写；新增能力没有既有实现时明确新增，不复制不相关代码。

## 3. 输入与输出

- 输入：用户请求、显式模型配置、注入的当前时钟。
- 输出：ResearchRequest、ResearchContext 或 VALIDATION_ERROR。
- 依赖：DV-15。
- 数据字段、状态、日期和预算使用总规约，不自定义同义字段或隐式空成功。

## 4. 行为规则

1. ticker 去首尾空格并转大写后须匹配现有正则；CIK 必须为 1–10 位数字并规范为 10 位，不接受浮点数或科学计数法。
2. as_of 为 2010-01-01 至美国东部当前日期的日历日；截止边界为下一日当地零点的开区间，不硬编码 UTC 偏移。
3. years 为 3–5 的整数；max_rounds 为 1–2，包含首次采集，且被两种补查循环共享。
4. PE 为有限十进制数，满足 0 < low < base < high <= 80；focus 不超过 1000 字符；未知字段拒绝。
5. model 必须属于启动时校验后的可用列表。请求接受后生成 run_id 和配置版本快照；运行中不得修改范围。
6. 默认 CAT/18230/2025-03-01、3 年、2 轮、PE 10/15/20。默认是产品初值，不是错误配置的替代值。

## 5. 失败、预算与安全

使用总规约 ErrorInfo 和全局 BudgetLedger；外部请求仅经 DV-15，实际发出前预留预算。业务缺口与系统异常分开，不以默认值、空对象、备用模型或备用来源掩盖错误。取消和终态优先级由 DV-13 统一控制，纯计算能力也不得提交已取消运行的结果。

本能力的特殊失败行为已在上面的规则与下面的场景中规定；不可恢复的供应商协议错误进入缺口，内部不变量错误由运行时标记 failed。

## 6. 验收场景

| 编号 | 场景 | Given | When | Then |
|---|---|---|---|---|
| DV-01-AC-01 | 正常请求 | 输入 CAT、18230、2025-03-01 及合法假设 | 接受请求 | CIK 为 0000018230，生成独立 run_id，范围被冻结 |
| DV-01-AC-02 | 未来截止日 | 注入纽约当前日期为 2025-03-01 | 提交 2025-03-02 | 拒绝请求且不发起任何数据请求 |
| DV-01-AC-03 | 非法数值 | PE 含 NaN、Infinity、零或逆序 | 校验 | 返回字段错误，不改成默认倍数 |
| DV-01-AC-04 | 时区边界 | 截止日落在夏令时切换附近 | 计算截止边界 | 使用 America/New_York 下一日零点而非固定偏移 |
| DV-01-AC-05 | 模型范围 | model 未配置或 years 为 3.5 | 提交 | 拒绝，不替换模型或截断财年数 |

## 7. 实现及特征测试映射

- 目标实现：backend/src/deepvalue 下的 capabilities/scope/；contracts/research.py。
- 计划测试：`tests/features/test_research_scope.py`；DV-14 的浏览器行为放在 `frontend/tests/research-workbench.spec.ts`，不重复用 Python 模拟 UI。
- 测试方法：固定输入和脱敏来源样本验证上述编号；涉及供应商的协议检查与真实接入验收分离；模型审查以固定合法/不合法输出验证路由和约束，不要求实时模型逐字相同。
- 当前阶段仅定义场景，不创建测试脚本。目标路径为计划，须与迁移矩阵一起随实现更新。
